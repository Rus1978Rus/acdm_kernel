# Legacy · Russian original

This folder is a frozen, self-contained snapshot of the original
Russian-language implementation of ACDM-KERNEL. It is kept for provenance only.

It still runs on its own:

```
python3 legacy/tests/test_battery.py    # 27 checks
python3 legacy/tests/test_ai_agent.py   # 14 checks
python3 legacy/tests/test_wiring.py     #  8 checks
```

The maintained, English version lives at the repository root. Everything here
is a mirror of that code as it stood at the moment of translation — do not
develop against it.
